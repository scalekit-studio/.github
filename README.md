# ScaleKit Studio organization documentation

This repository owns the public GitHub organization profile and the shared contributor,
security, support, and pull request guidance used across ScaleKit Studio repositories.

## Files

- `profile/README.md`: public organization profile.
- `CONTRIBUTING.md`: branch, review, validation, and release workflow.
- `SECURITY.md`: private vulnerability reporting policy.
- `SUPPORT.md`: product support and engineering issue boundaries.
- `PULL_REQUEST_TEMPLATE.md`: the minimum evidence expected in a pull request.

Keep this repository free of credentials, private infrastructure identifiers, internal
roadmaps, and agent memory. Product-specific setup belongs in that product's README;
private project continuity belongs in the internal project record.
