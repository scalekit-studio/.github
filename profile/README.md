ScaleKit Studio builds adaptive software systems that combine durable product
infrastructure, generative interfaces, and authorized execution across web, local, and
cloud environments.

## Platform map

| Repository | Responsibility |
| --- | --- |
| [`scalekit.studio`](https://github.com/scalekit-studio/scalekit.studio) | Public website and browser-native entry surface |
| [`sks-api`](https://github.com/scalekit-studio/sks-api) | Shared identity, durable data, tasks, and integration plane |
| [`sksya-api`](https://github.com/scalekit-studio/sksya-api) | SKSYA reasoning, orchestration, capabilities, and generated views |
| [`sksya-app`](https://github.com/scalekit-studio/sksya-app) | Dedicated SKSYA web control surface |
| [`sksya-exec`](https://github.com/scalekit-studio/sksya-exec) | Authorized local or cloud browser and computer execution |
| [`sks-sbar`](https://github.com/scalekit-studio/sks-sbar) | Framework-independent scrollbar package for ScaleKit interfaces |

Most product repositories are private while the platform is under active development.

## Engineering

Changes move through reviewed feature branches, repository CI, immutable integration
artifacts, and an isolated cross-service review environment before production promotion.
The shared workflow is documented in
[`CONTRIBUTING.md`](https://github.com/scalekit-studio/.github/blob/main/CONTRIBUTING.md).

For product questions, see [`SUPPORT.md`](https://github.com/scalekit-studio/.github/blob/main/SUPPORT.md).
For vulnerabilities, use the private process in
[`SECURITY.md`](https://github.com/scalekit-studio/.github/blob/main/SECURITY.md).
