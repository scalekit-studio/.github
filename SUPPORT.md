# Support

## Product and account support

Use `hello@scalekit.studio` for product access, account, billing, partnership, or general
support. Do not include passwords, session cookies, private keys, recovery codes, or full
payment details.

## Engineering issues

Use the affected repository's issue tracker for reproducible, non-sensitive defects when
issues are enabled. Include the version or commit, environment, minimal reproduction,
actual result, expected result, and relevant sanitized logs.

Repository issues are not an incident-response channel and do not guarantee immediate
support. Never post a suspected vulnerability publicly. Use
[`SECURITY.md`](SECURITY.md) instead.

## Internal development questions

Start with the repository README, then its code-adjacent runbooks. Shared branch, review,
nightly, and release behavior is documented in [`CONTRIBUTING.md`](CONTRIBUTING.md).
